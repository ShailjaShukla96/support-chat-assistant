# Choosing a model
> SAMPLE CONTENT: replace with approved Caramel AI documentation before pilot

Pick a model by balancing quality, speed, and cost:
- Larger models give better reasoning and longer, more careful answers, but respond more slowly and cost more per token.
- Smaller models are faster and cheaper and work well for classification, extraction, and short answers.
- Start with a smaller model and move up only if quality is not good enough.
- Always test with your own prompts before switching in production.

Model names must match exactly what is listed for your account. A wrong name returns a 404 error.
